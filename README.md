# Kernel Panic (working title)

A browser-based escape room for the **iWISE Ai & Web Programming Challenge (Escape Room)**. You are an intruder trapped inside a locked-down computer. A trace countdown is running, and the only way out is to crack five security layers using CTF-style puzzles, ending with a conversation with the machine's AI gatekeeper.

Everything in the game is simulated and fictional. No real systems, targets or exploit code are involved.

> **Note:** All documents here describe a plan, not a final specification. Scope, stages, stack choices and numbers may change as open questions are answered and as development shows what is practical.
